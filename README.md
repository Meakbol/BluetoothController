# BluetoothController

## Description / ការពិពណ៌នា

This is an iOS application developed using Swift and Xcode to control Arduino devices via Bluetooth.  
នេះគឺជាកម្មវិធី iOS ដែលបង្កើតដោយប្រើ Swift និង Xcode ដើម្បីបញ្ជា Arduino តាមរយៈ Bluetooth។

## Features / លក្ខណៈពិសេស
- Connect to Bluetooth modules (e.g., HC-05)
- Send commands to Arduino (e.g., control motor or servo)
- Simple user interface for testing

- តភ្ជាប់ទៅម៉ូឌុល Bluetooth (ឧ. HC-05)
- ផ្ញើពាក្យបញ្ជាដល់ Arduino (ឧ. បញ្ជាម៉ូទ័រ ឬ សឺវ៉ូ)
- មានចំណុចប្រើប្រាស់ងាយស្រួលសម្រាប់សាកល្បង

## Requirements / លក្ខខណ្ឌ
- iOS 13+
- Xcode 14+
- Bluetooth module + Arduino board

## Getting Started / ដំណើរការចាប់ផ្តើម

1. Clone the repository:
    ```bash
    git clone https://github.com/Meakbol/BluetoothController.git
    ```

2. Open the `.xcodeproj` in Xcode.

3. Build and run on your iPhone or Simulator.
